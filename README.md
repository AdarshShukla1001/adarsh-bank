# 🏦 Adarsh Bank - Java & Spring Boot Learning Lab

Welcome to **Adarsh Bank**! This is not just a banking application; it's a **fun and interactive playground** designed to master Java and Spring Boot from the ground up.

## 🎯 Project Goal
The objective of this project is to build a robust banking system while becoming a **Java Power User**. We are focusing on:
- Clean Code & Best Practices.
- Spring Boot Architecture (REST, Services, Repositories).
- Data Persistence and Security.
- Real-world problem solving.

## 🛠 Tech Stack
- **Language**: Java 17+
- **Framework**: Spring Boot 3.x
- **Build Tool**: Maven (via `./mvnw`)
- **IDE**: Any (VS Code, IntelliJ, Eclipse)

## 🚀 How to Run
To start the application, use the Maven Wrapper:
```bash
./mvnw spring-boot:run
```

This project is continuously evolving. Every new concept learned is documented in the `learning/` folder with proper structure and exercises.
